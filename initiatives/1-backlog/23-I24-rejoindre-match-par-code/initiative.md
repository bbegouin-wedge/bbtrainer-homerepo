# I24 — Rejoindre un match par code

Fusion de deux moitiés d'une même évolution :

- **automaton A29** (non définie) : la route de résolution d'un code et le jeton de place ;
- **bloodbowltrainer B10** : à l'accueil, « REJOINDRE », taper son code et se retrouver à sa place,
  sans connaître ni le `game_id` ni son `coach_id`.

La carte du client est reprise dans `reprise/`, comme matière du grilling.
